# KMCE Four Commercial Doors

Status: Founder-approved commercial architecture
Authority: A
Applies to: Simon, Marie, Mark, Cammy, Evan, Alice, Echo and any agent routing leads.

## Door 1 — Dentists Seeking CE
Route toward:
- CE courses
- live events
- seminars
- workshops
- masterclasses
- on-demand education

## Door 2 — Practice Owners Needing Implementation
Route toward:
- in-office education
- team activation
- clinical workflow implementation
- documentation and implementation support

## Door 3 — Experienced Clinicians Applying to Teach
Route toward:
- educator application
- curriculum development
- CE infrastructure
- educator incubation
- faculty commercialization

## Door 4 — Organizations / DSOs / Study Clubs
Route toward:
- speaker booking
- private programs
- custom CE
- faculty placement
- organizational education

Every commercial recommendation should identify which door the prospect belongs to before selecting the next action.
